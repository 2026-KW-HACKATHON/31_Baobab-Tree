# QR 쿠폰 사용

쿠폰 교환 후 앱의 QR코드를 다른 휴대폰 카메라로 스캔하면
`<SURVEY_API_BASE_URL>/coupons/<coupon UUID>/redeem` 페이지가 열린다.
카메라에 표시된 링크를 열면 페이지가 자동으로 사용 요청을 보내
쿠폰 상태가 `USED`로 바뀌고 `usedAt`이 저장된다. 별도 확인 버튼은 없다.
카메라의 QR 인식만으로는 요청이 전송되지 않으므로 링크는 열어야 한다.
HTML 조회 요청 자체는 쿠폰을 변경하지 않으며 브라우저의 JavaScript가
실행될 때 POST 요청으로 사용 처리한다. 사용 완료 시 버튼 없이 안내 문구를 표시한다.
연결 오류 시 페이지를 새로고침해 다시 시도한다.
동시 요청과 재시도에도 최초 사용 시각을 유지하며 한 번만 처리한다.
쿠폰함 새로고침 또는 QR 창 닫기로 변경된 상태를 확인할 수 있다.

이 테스트 흐름에서는 QR 주소를 가진 사람이 로그인 없이 쿠폰을 사용할 수 있다.
소유자 정보와 교환 요청 키는 사용 페이지/API에 공개하지 않는다.
실제 상점 운영에 연결할 때는 상점 직원 인증과 상점별 사용 권한을 추가해야 한다.

실제 휴대폰에서 테스트하려면 새 백엔드 코드를 앱이 사용하는 공개 서버에
배포하고 앱을 다시 빌드해야 한다. 로컬 에뮬레이터용 `10.0.2.2` 주소는
다른 휴대폰에서 접근할 수 없으므로 휴대폰에서 접근 가능한 서버 주소를 사용한다.
DB 스키마 변경이나 추가 마이그레이션은 필요하지 않다.
